**Last Last Week** [font:28.0pt]

**Research ** [font:20.0pt]

**Filtering  noise, Vibration Calibration by using “Go-RIO + Uncertainty Aware + Iterated Kalman Filter”** [font:18.0pt]
**Go-RIO : Using concentric zone to separate noise, Using GP to make 6DOF with asynchronized radar + imu** [font:18.0pt]
**Uncertainty Aware : Propagates the GP posterior variance into per-point post-undistortion uncertainty (Σ_p) and performs motion-                                            compensated point cloud undistortion** [font:18.0pt]
**IKF :  Estimates the state by assigning different weights to each point according to its post-undistortion uncertainty** [font:18.0pt]

[TABLE 2x1]
  Row 0: ['Go-RIO']
  Row 1: ['Fuses IMU and Radar Doppler via Gaussian Process to infer the sensor pose (position + orientation) and its uncertainty at any arbitrary time t']

[TABLE 2x1]
  Row 0: ['Uncertainty Aware']
  Row 1: ['Converts the GP uncertainty output by Go-RIO into per-point positional uncertainty (Σ_p) and performs point cloud undistortion']

[TABLE 2x1]
  Row 0: ['IKF']
  Row 1: ['Takes the undistorted points and their uncertainty (Σ_p), assigns higher weights to more reliable points, and estimates the final 6DOF state']
